# rfc-library/navigation Specification

## Purpose
约束 RFC 文档区对读者的可达路径:左侧导航只提供两篇文档的入口,节级定位靠页内目录、相邻页
与深链完成,使百余个小节页不淹没既有导航结构。

## Requirements

### Requirement: 左侧导航只提供两个文档入口

站点左侧导航 MUST 新增且只新增两个与 RFC 文档区相关的入口:RFC 8299 与 RFC 9182 的落地页。
小节页 MUST NOT 出现在左侧导航中。既有导航项(Home、POC)的顺序与可见性 MUST NOT 改变。

#### Scenario: 导航条目数量受控

- **WHEN** 读者展开站点左侧导航
- **THEN** 除既有的 Home 与 POC 入口外只多出两项,分别指向两篇 RFC 的落地页,导航不出现小节级条目

#### Scenario: 既有入口不受影响

- **WHEN** 比较加入文档区前后的导航
- **THEN** Home 仍排在首位、POC 入口的标题与位置不变

### Requirement: 落地页提供完整页内目录

每篇 RFC 的落地页 MUST 提供该文档的节级目录:列出全部编号小节(含深层小节)的小节号与标题,
每项链接到对应小节页;目录本身是站点自撰外壳,MUST NOT 混入任何一节的正文区间。

#### Scenario: 从落地页进入任一小节

- **WHEN** 读者在落地页目录中点击 `6.3.2.2  Connection`
- **THEN** 打开的页面承载该小节的原文区间,且页面标题显示 `RFC 8299 §6.3.2.2 Connection`

#### Scenario: 目录覆盖完整

- **WHEN** 核对落地页目录条目与该篇被切分的小节集合
- **THEN** 两者一一对应,没有目录里存在但页面缺失的小节,也没有页面存在但目录缺失的小节

### Requirement: 小节页有稳定的可深链地址

每个小节页 MUST 有仅由文档号与小节号决定、可人工读出的地址,且该地址在重新生成后保持稳定;
读者从外部(搜索结果、页内目录、粘贴的链接)到达该地址时 MUST 直接落在对应小节。

#### Scenario: 深链直达

- **WHEN** 在新标签页直接打开某个小节页地址
- **THEN** 页面呈现该小节正文与其合规外壳,无需依赖上一页的会话状态

#### Scenario: 重新生成不改变地址

- **WHEN** 源副本不变而重新生成全部小节页
- **THEN** 每个小节页的地址与上一次生成一致

### Requirement: 小节页提供相邻页与回到上级的路径

每个小节页 MUST 提供回到该篇落地页的路径,以及到该文档中前一节与后一节的链接,使读者可以
顺序通读而不必回到目录逐次点击。

#### Scenario: 顺序通读

- **WHEN** 读者连续点击"下一节"
- **THEN** 按原文顺序逐节前进,到达第一节之前与最后一节之后时链接行为明确(不出现指向不存在页面的链接)

#### Scenario: 回到上级

- **WHEN** 读者在小节页点击返回入口
- **THEN** 到达该篇落地页的目录位置
